      📱 iPhone Setup Guide
      OPTION A · Add to Home Screen (Offline)
      1. Host this file on GitHub Pages (free)
      2. Open the URL in Safari on iPhone
      3. Tap the Share button (box with arrow)
      4. Scroll down → tap "Add to Home Screen"
      5. Name it MERIDIAN → tap Add
      6. App icon appears on your home screen ✓
      7. Works offline — data saved to phone
      OPTION B · Host on GitHub Pages (Free)
      1. Go to github.com → New repository
      2. Name it meridian → Public
      3. Upload index.html, manifest.json, sw.js
      4. Go to Settings → Pages → Branch: main
      5. Your URL: username.github.io/meridian
      6. Open on iPhone Safari → Add to Home Screen
